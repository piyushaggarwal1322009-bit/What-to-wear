# 👕 What Should I Wear

A practical, context-aware weather recommendation website that tells you what to wear based on the weather and what you are doing.

## Overview
This application takes your location and your current situation (e.g., College, Interview, Wedding, Gym, Outdoor Event) and provides a practical recommendation for what to wear, carry, and avoid, along with reasoning.

## How to Run Locally
1. Ensure Node.js is installed.
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env.local` and add any necessary API keys (optional if using free Open-Meteo).
4. Run the development server: `npm run dev`
5. Open `http://localhost:3000`

## Features
- Context-aware recommendations
- Real-time weather fetching
- Mobile-responsive design
